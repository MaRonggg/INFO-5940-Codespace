Implementation:

## Task3.1

### Efficiently handle large documents by chunking them into smaller pieces.
Implementation: 
1. I used `RecursiveCharacterTextSplitter` to define a text splitter with **chunk_size = 200** and **chunk_overlap = 50**. 
2. I used `text_splitter.split_documents(document_list)` to recursively chunk all uploaded documents to smaller pieces

## Task3.2 & 3.3

### Implement a retrieval component that searches the document chunks to find the most relevant information for a user query. Use a language model to generate responses based on the retrieved chunks.
Implementation: 
1. **Chromadb** was used to embedding and store chunked documents (now vectors) with an Openai model. 
2. I defined a class named **State**, which is a map. And created a retrieval function using `vectorstore.similarity_search`, which will return relevant contents. 
3. I added this retrival function to the LangGraph with the user's question. 
4. After the LangGraph runs, the **State** map will contain user question, list of relevant contents, but no answer. 
5. Due to the limitations of **Streamlit**, I abandoned the plan of adding the function of generating responses to LangGraph. Instead, I used `st.chat_message("user").write(question)`to inform **Streamlit** of the user's question, and fetched and merged relevant contents generated by LangGraph. And input it into **Streamlit**, `client.chat.completions.create` will take the openai model and relevant contents to generate responses, and `st.write_stream(stream)` allows user to see the response while it is being generated.

## About GitHub Codespaces

[Codespaces](https://docs.github.com/en/codespaces) is a complete software development and execution environment, running in the cloud, with its primary interface being a VSCode instance running in your browser.

Codespaces is not free, but their per-month [free quota](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces#free-quota) is generous.  Codespaces is free under the [GitHub Student Developer Pack](https://education.github.com/pack#github-codespaces).

## Running a Streamlit App on Codespaces  
Follow these steps to launch and view your Streamlit app in GitHub Codespaces:
1. **Open the terminal** inside your Codespace.
2. Run the command:  
   ```bash
   streamlit run your-file-name.py
   ```  
   **(Replace `your-file-name.py` with the actual name of your Streamlit app file, e.g., `hello_app.py`.)**
3. After pressing **Enter**, a popup should appear in the bottom-right corner of Codespace editor.  
   - Click **“Open in Browser”** to view your app.  

   ⚠️ *If you miss the popup:*  
   - Press **Ctrl + C** in the terminal to stop the app.  
   - Rerun the command from step 2 — the popup should appear again.
4. A new browser tab will open, showing the interface of your Streamlit app.
5. **Make changes to your code** in the Codespace editor.  
   - Refresh the browser tab to see the updated version of your app.
